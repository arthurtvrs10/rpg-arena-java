# RPG Arena API

Open-source turn-based RPG backend built with Java 21 and Spring Boot as a six-month software engineering portfolio project.

The repository currently contains the application foundation and the complete product specification. Features are delivered incrementally through the 24-week roadmap; documented requirements must not be presented as already implemented.

## Target stack

Java 21, Spring Boot 4.1.x, PostgreSQL, Flyway, Spring Security, JWT, JUnit, Testcontainers, Bruno, Docker and GitHub Actions.

## Current bootstrap

```bash
./mvnw clean test
./mvnw spring-boot:run
```
