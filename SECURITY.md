# Security Policy

The RPG Arena maintainers take security seriously. We appreciate your efforts to responsibly disclose findings.

---

## Supported Versions

Only the latest active development version is supported for security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

Please **do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.**

To report a vulnerability privately:

1. Navigate to the repository on GitHub: [https://github.com/arthurtvrs10/rpg-arena-java](https://github.com/arthurtvrs10/rpg-arena-java).
2. Click on the **Security** tab.
3. Select **Advisories** (or navigate directly to [Report a Vulnerability](https://github.com/arthurtvrs10/rpg-arena-java/security/advisories/new)).
4. Click **New draft security advisory**.
5. Provide a detailed summary, including:
   - A description of the vulnerability.
   - Affected components, endpoints, or classes.
   - Step-by-step instructions or proof-of-concept to reproduce the issue.
   - Potential impact of the issue.

The maintainer will review the advisory, validate the issue, and coordinate a fix in private before publishing a security patch.
