# Episódio 05 - Transformando o RPG em uma API REST previsível

- **Semanas:** 9 e 10
- **Publicação planejada:** 01/11/2026
- **Duração:** 12-18 minutos
- **Thumbnail:** API QUE OUTROS CONSEGUEM USAR

## Hook

Uma API que funciona só no seu Postman não é uma API pronta.

## Promessa

Criar contratos, erros, validação, OpenAPI e coleção Bruno executável.

## Demonstração final

CRUD de personagem e inventário com conflito de versão.

## Blocos técnicos

- REST
- DTOs
- Problem Details
- Bruno e OpenAPI

## Roteiro

1. Abra com a consequência do problema.
2. Mostre o estado anterior em até 30 segundos.
3. Explique a decisão e uma alternativa descartada.
4. Mostre somente os trechos de código necessários.
5. Execute teste ou Bruno para provar a regra.
6. Mostre o resultado ponta a ponta.
7. Conte um erro real e o que mudou.
8. Feche com: Rode a coleção Bruno versionada.

## Shot list

- Abertura falando para câmera ou tela com título.
- Diagrama limpo do problema.
- Diff antes/depois.
- Execução de teste.
- Demo funcional.
- GitHub PR/release.
