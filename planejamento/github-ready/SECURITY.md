# Security Policy

## Supported versions

Only the latest public release receives security fixes during the learning phase.

## Reporting

Do not open a public issue for a vulnerability. Use GitHub private vulnerability reporting when enabled. Include affected version, reproduction, impact, and suggested mitigation. Do not include real credentials or personal data.

## Scope

Authentication bypass, broken resource ownership, privilege escalation, token/session issues, injection, secret exposure, and unsafe administrative operations are in scope.
