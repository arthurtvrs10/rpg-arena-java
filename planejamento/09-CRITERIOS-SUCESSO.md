# Critérios finais de sucesso

Ao final das 24 semanas, demonstre cada item com um link, teste, PR, release ou vídeo.

- [ ] Constrói e executa um backend completo com Java 21 e Spring Boot.
- [ ] Modela regras de personagem, combate, inventário, progressão, missão, mundo e economia com orientação a objetos.
- [ ] Usa PostgreSQL, SQL, migrations, índices, transações e concorrência com evidência.
- [ ] Entrega API REST com JWT, refresh, roles, ownership, validação e erros padronizados.
- [ ] Mantém testes unitários, integração com PostgreSQL, segurança, arquitetura, smoke e carga mínima.
- [ ] Valida jornadas no Bruno e publica OpenAPI utilizável.
- [ ] Trabalha com issues, branches, commits, PRs, reviews, CI, releases e changelog.
- [ ] Executa localmente por Docker Compose e publica ambiente HTTPS com runbook e rollback.
- [ ] Mantém README, ADRs, diagramas, guia de contribuição e documentação operacional.
- [ ] Explica decisões, trade-offs, erros e melhorias usando o próprio código.
- [ ] Publica 12 episódios, 24 Shorts e uma demonstração técnica final.
- [ ] Usa o projeto em currículo, GitHub, entrevistas e candidaturas sem esperar perfeição.

Crie `docs/portfolio/evidence.md` com uma linha por critério: evidência, link, decisão e aprendizado.
