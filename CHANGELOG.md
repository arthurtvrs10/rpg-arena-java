## [0.1.0-dev] - 2026-08-17

### Added
- Comprehensive open-source repository foundation and governance structure.
- English and Portuguese documentation suite (`README.md`, `README.pt-BR.md`, `docs/`).
- 30-Day intensive engineering roadmap comprising 4 sprints and 24 structured daily tasks.
- Architecture Decision Record template (`docs/adr/000-template.md`).
- GitHub workflow automation (`.github/workflows/ci.yml`), Dependabot (`.github/dependabot.yml`), CODEOWNERS, and issue templates.
- Security disclosure policy (`SECURITY.md`), Code of Conduct (`CODE_OF_CONDUCT.md`), and contributing guidelines (`CONTRIBUTING.md`).
