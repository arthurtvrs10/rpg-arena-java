# Changelog de requisitos

## 1.0 — 20/08/2026

- consolidada a visão de seis meses com o repositório Java existente;
- fechado escopo funcional da versão 1.0;
- definidos 96 requisitos funcionais e 28 não funcionais;
- definidas regras, fórmulas, estados, limites e catálogo de erros;
- definidos 19 casos de uso e critérios BDD prioritários;
- definido modelo de segurança, ownership 404, JWT/refresh e idempotência;
- definido modelo/dicionário de dados e ordem de migrations;
- criado contrato OpenAPI inicial;
- definido conteúdo mínimo demonstrável e ordem exata de implementação;
- ligados requisitos às semanas, testes e releases.
